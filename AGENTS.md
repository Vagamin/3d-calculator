# Инструкции для ИИ-агента

- Сайт публикуется из папки `pwa/` через GitHub Pages (репозиторий https://github.com/Vagamin/3d-calculator, ветка `main`).
- После любых изменений в проекте:
  1. Если менялись файлы в `pwa/` — увеличить `CACHE_VERSION` в `pwa/sw.js`.
  2. Закоммитить и запушить: `git add -A`, `git commit -m "<краткое описание на русском>"`, `git push`.
  3. Убедиться, что запуск workflow «Deploy to GitHub Pages» завершился успешно (`gh run list --limit 1`).
- Не пушить несколько раз подряд за секунды — дождаться окончания предыдущей публикации.
- Изменения в `pwa/index.html` дублировать в `3d-cost-calculator v6.html`, если они касаются самого калькулятора (не PWA).
