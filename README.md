# Калькулятор себестоимости 3D-печати — PWA

**Адрес приложения:** https://vagamin.github.io/3d-calculator/

## Обновление сайта
Если нужно что-то поменять, отредактируйте файлы в этой папке, поднимите версию в `sw.js`
(`CACHE_VERSION = 'v2'` → `'v3'`) и выполните в этой папке:

```
git add -A
git commit -m "Обновление"
git push
```

Через 1–2 минуты изменения появятся на сайте.

## Состав
- `index.html` — приложение
- `manifest.webmanifest` — название, иконки, цвета приложения
- `sw.js` — офлайн-режим (кэширует все файлы)
- `libs/` — html2canvas и jsPDF (локально, PDF работает без интернета)
- `icons/` — иконки приложения

## Публикация (бесплатно)

### Вариант A — Netlify Drop (проще всего, 2 минуты)
1. Откройте https://app.netlify.com/drop и войдите (через GitHub/Google/почту).
2. Перетащите **папку `pwa` целиком** в окно браузера.
3. Получите адрес вида `https://xxx.netlify.app`. В Site configuration → Change site name можно задать понятное имя.
4. Обновление: Deploys → перетащить папку заново.

### Вариант B — GitHub Pages
1. Зарегистрируйтесь на https://github.com, создайте публичный репозиторий (например `3dcalc`).
2. «Add file → Upload files» → перетащите **содержимое** папки `pwa` (index.html должен быть в корне) → Commit.
3. Settings → Pages → Source: «Deploy from a branch», Branch: `main` / `(root)` → Save.
4. Через 1–2 минуты сайт будет доступен по `https://<логин>.github.io/3dcalc/`.

## Установка
- **Android (Chrome):** откройте адрес → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- **ПК (Chrome / Edge):** откройте адрес → значок установки ⊕ справа в адресной строке (или меню → «Приложения» → «Установить»).

После первого открытия приложение работает без интернета.

## Обновление приложения
После изменения любых файлов увеличьте версию в `sw.js`:
`const CACHE_VERSION = 'v1';` → `'v2'` — и загрузите файлы на хостинг заново.
У пользователей обновление подтянется при следующем запуске с интернетом.

## Важно
- Нужен HTTPS — Netlify и GitHub Pages дают его автоматически.
- Открытие `index.html` двойным кликом работает, но без установки и офлайн-режима.
