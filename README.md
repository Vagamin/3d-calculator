# Калькулятор себестоимости 3D-печати

**Приложение:** https://vagamin.github.io/3d-calculator/

## Структура
- `pwa/` — приложение, которое публикуется на сайт
  - `index.html` — калькулятор
  - `manifest.webmanifest` — название, иконки, цвета
  - `sw.js` — офлайн-режим
  - `libs/` — html2canvas и jsPDF
  - `icons/` — иконки
- `3d-cost-calculator v6.html` — исходная однофайловая версия (на сайт не публикуется)
- `.github/workflows/pages.yml` — автопубликация папки `pwa` на GitHub Pages

## Обновление
1. Внесите изменения в файлы `pwa/`.
2. Увеличьте `CACHE_VERSION` в `pwa/sw.js` (например `'v2'` → `'v3'`).
3. Выполните в корне проекта:
   ```
   git add -A
   git commit -m "Описание изменений"
   git push
   ```
Через 1–2 минуты сайт обновится. У пользователей обновление подтянется при следующем запуске с интернетом.

## Установка
- **ПК:** Edge или Chrome → кнопка «Установить приложение» на странице или значок в адресной строке.
- **Android:** Chrome → «Установить приложение» или меню ⋮ → «Установить приложение».
